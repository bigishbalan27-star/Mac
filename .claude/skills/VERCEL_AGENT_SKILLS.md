# Vercel agent skills

The 9 skills from [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills) `skills/` at commit `5a37a63`. The repo's README gives the licence as MIT (Vercel, Inc.). The repo has no LICENSE file.

Installed under their frontmatter names: vercel-composition-patterns, deploy-to-vercel, vercel-react-best-practices, vercel-react-native-skills, vercel-react-view-transitions, vercel-cli-with-tokens, vercel-optimize, web-design-guidelines, writing-guidelines. The packaged `.zip` copies were left out.

deploy-to-vercel, vercel-cli-with-tokens and vercel-optimize need the Vercel CLI and a Vercel login or token. Store a token as an environment secret, never in chat or commands. To update, run `npx skills update` or copy `skills/*` again.
