# AI Video Studio

My AI video editing workspace.

| Folder | What goes in it |
|---|---|
| `References/` | Videos whose style I like |
| `Approved Videos/` | Finished edits I've signed off on |
| `Editing Style/` | My written editing rules |
| `Brand Kit/` | Logos, colors, fonts, intros/outros, music |
| `Raw/` | One subfolder per video to be edited |
| `Exports/` | Rendered drafts waiting for review |

**Workflow:** `Raw/` → `Exports/` (draft) → `Approved Videos/` (final)

Large video files are best kept in Descript or Google Drive, with links noted here, since GitHub limits files to 100 MB.
