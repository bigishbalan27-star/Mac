# Exports

Rendered drafts waiting for your review.

**What goes here**
- Every video exported from an editing job, named to match its folder in Raw, with a version number (e.g. `podcast-ep12_v1.mp4`, `podcast-ep12_v2.mp4`)
- Platform versions of the same edit (e.g. `_9x16` for Reels/TikTok/Shorts, `_16x9` for YouTube)
- Optional: a `feedback.md` with your notes on each draft

**How it's used:** Review drafts here and give feedback. Once you approve a version, it moves to Approved Videos.
