# Raw

Unedited footage. **Create one subfolder per video you want edited.**

**Example layout**
```
Raw/
  2026-11-podcast-ep12/
    main-camera.mp4
    b-roll/
    notes.md
  product-launch-teaser/
    ...
```

**What goes in each video folder**
- All raw clips, audio, and B-roll for that video
- A `notes.md` with: target platform and length, the key message or hook, must-keep moments, anything to cut, and the deadline

**How it's used:** Each subfolder is one editing job. When it's done, the final version goes into Approved Videos.
